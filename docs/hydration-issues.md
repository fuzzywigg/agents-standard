### Issue 6: [copilot] Add CI workflow — Markdown linting and link checking

**Status:** ACTIVE | **Tier:** 1 | **Created:** 2026-04-13 | **Owner:** copilot
**Source links:** `.github/workflows/` (missing), AGENTS.md Part 11 (testing protocol)
**Edit policy:** Agent-editable; must pass validation before merge

**Problem**

No CI/CD exists. `AGENTS.md` is a critical 1770-line document injected into agent sessions. A single formatting error, broken internal reference, or structural corruption could degrade all downstream agents. There is no automated gate to catch these issues before they reach `alpha`.

**Proposed Solution**

Create `.github/workflows/validate.yml` that runs on every PR:
1. **markdownlint** — enforce consistent Markdown formatting
2. **markdown-link-check** — detect broken internal/external links
3. **AGENTS.md structure check** — verify required sections (Parts 1-21) are present (simple grep)
4. **Spell check** (optional, non-blocking) — via `cspell`

```yaml
name: Validate Docs
on: [pull_request, push]
jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '20' }
      - run: npm install -g markdownlint-cli markdown-link-check
      - run: markdownlint "**/*.md" --ignore node_modules
      - run: markdown-link-check README.md AGENTS.md CLAUDE.md --config .mlc-config.json
```

**Acceptance Criteria**
- [ ] `.github/workflows/validate.yml` exists
- [ ] Workflow runs on PR and push to alpha
- [ ] markdownlint passes on all .md files
- [ ] markdown-link-check passes (with allowlist for Notion URLs that may 403)
- [ ] Workflow status badge added to README
